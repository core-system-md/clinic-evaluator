# ADR-005 — خصوصية قواعد ومنهجية التقييم

**الحالة:** Accepted

## القرار

تُعامل قواعد الحساب الداخلية للتقييم كملكية خاصة للنظام.

المستخدم يحتاج إلى:
- رؤية الأسئلة والخيارات اللازمة للإجابة.
- رؤية نتيجته وشرحها النهائي المسموح بعرضه.

ولا يحتاج إلى الوصول إلى:
- أوزان الإجابات.
- معادلات الحساب.
- قواعد الـTraps والعقوبات الداخلية.
- خرائط KPI/EV الداخلية.
- أي configuration تكشف طريقة الوصول إلى النتيجة.

## التصميم المستهدف

- المتصفح يقدم تجربة إجابة سريعة.
- الخادم يعيد حساب النتيجة الرسمية من الإجابات الأصلية وإصدار التقييم.
- النتيجة التي يحفظها النظام أو يستخدمها في التقرير/الاستحقاقات هي النتيجة الرسمية.
- قواعد الحساب الخاصة لا تُعتبر جزءاً من API العام.

## ملاحظة التدقيق

الكود الحالي ما زال يحتوي نسخة منطق الحساب داخل engine/engine.js ويدعم تحميل config.json محلياً، ولذلك هذا القرار اتجاه معماري مستهدف وليس إصلاحاً مطبقاً بعد.

**يكمل ADR-002.**
