# Matrix Comprehensive Assessment
- Slug: `matrix-comprehensive-assessment`; Arabic title: **تقييم Matrix الشامل**.
- New independent family; existing assessment families and their historical results remain unchanged.
- Nine axes/roles, 18 required bilingual situational questions, 72 stable option IDs. Each question contains 0/40/70/100 once. Axis weights total 100%; expected duration 5–7 minutes.
- KPI outputs: TFI, TAP, PRP, PLI, PSI, NPI, EVI, TCI, RRI. Each role map uses measured roles and sums to 1.0.
- Scoring is resolved by the shared engine and stable option identity registry. Economic-opportunity simulation is disabled.
- Scores are descriptive and uncalibrated: no pass/fail or validated Q1–Q4 maturity-stage claim.
- The static HTML will use the shared runtime. Homepage catalog is data-driven and exposes families after protected publication/release.
